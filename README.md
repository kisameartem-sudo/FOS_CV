# Фонд оценочных средств по дисциплине «Современные методы компьютерного зрения»

Этот репозиторий предназначен для открытого и воспроизводимого представления фонда оценочных средств (ФОС) по дисциплине «Современные методы компьютерного зрения» (Б1.В.06, направление 01.03.02 Прикладная математика и информатика). Здесь объединены рабочая программа дисциплины, модель измерения результатов обучения, контрольно-измерительные материалы (КИМ), критерии оценивания, методические рекомендации и используемые образовательные ресурсы. Результаты обучения связываются с компетентностно-ролевой моделью в области искусственного интеллекта (КРМ версии 3.0).

## 1. О дисциплине

**Цель дисциплины.** Сформировать систематизированное представление о современных архитектурах нейронных сетей для компьютерного зрения и практические навыки их применения к анализу изображений и видео.

**Объём:** 144 часа / 4 зачётные единицы. Дисциплина включает 32 часа лекций, 48 часов лабораторных работ, самостоятельную работу и завершается экзаменом.

**Модули:**

1. Фундаментальные архитектуры и методы глубокого обучения для зрения.
2. Детекция, сегментация и генерация изображений.
3. Внимание, трансформеры и метрическое обучение.
4. Продвинутые и гибридные методы.

По завершении дисциплины обучающийся применяет CNN и трансформеры, реализует модели детекции, сегментации, генерации, image captioning и OCR, оценивает качество и обосновывает архитектурные решения. Полное описание приведено в [РПД](docs/rpd.md).
