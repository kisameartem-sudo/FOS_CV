# Демонстрационные baseline-решения

В данном каталоге размещены демонстрационные baseline-решения для лабораторных работ дисциплины **«Современные методы компьютерного зрения»**.

Материалы подготовлены как часть учебно-методического обеспечения дисциплины и предназначены исключительно для демонстрации рекомендуемой структуры программного решения.

> Важно: данные материалы **не являются готовыми решениями лабораторных работ**. Во всех оцениваемых местах сохранены заготовки (`TODO`, `NotImplementedError`), которые должны быть реализованы студентом самостоятельно.

---

## Назначение

Baseline-файлы помогают студенту:

- понять рекомендуемую структуру проекта;
- корректно организовать импорт библиотек;
- подготовить окружение;
- загрузить набор данных;
- оформить цикл эксперимента;
- подготовить функции обучения и тестирования;
- сформировать итоговый отчет по экспериментам.

При этом реализация ключевых алгоритмов остается самостоятельной частью лабораторной работы.

## Использование

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
   pip install -r requirements-course.txt
   pip install jupyter
   ```

2. Откройте выбранную заготовку:

   ```bash
   jupyter lab baselines/baseline-lab01-viola-jones.ipynb
   ```

3. Реализуйте отмеченные заготовки, проведите эксперимент и подготовьте выводы по критериям соответствующего КИМ.
