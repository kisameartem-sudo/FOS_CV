# Исходные документы

В каталоге сохранены исходные DOCX, использованные как справочные материалы при подготовке Markdown-документации репозитория.

DOCX размещены только как архивные источники. Их повторное использование, изменение или распространение допускается при наличии разрешения правообладателя либо иного применимого правового основания. Лицензия CC BY 4.0 распространяется на оригинальные материалы репозитория только в пределах, указанных в [`LICENSE.md`](../../LICENSE.md).

Содержимое исходных документов может отличаться от актуальной адаптированной версии ФОС. Нормативной для этого репозитория является текущая Markdown-документация.
